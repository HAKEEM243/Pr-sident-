# Rail Empire — base de jeu de train

- `index.html` + `game.js` : base jouable (ouvrez `index.html`, ou la page publiée sous `/train-starter/`).
- `BLUEPRINT.md` : le guide pour construire le vrai jeu (correspondance avion → train, architecture, jalons, pièges, prompt de départ).

Dans la base : 12 gares européennes, 4 types de trains, ouverture de lignes, calendrier de départs fixes par jour,
trajet = accélération → palier → freinage, trains animés sur la carte, revenus et coûts à chaque trajet, vitesses jusqu'à Turbo,
rattrapage du temps hors du jeu, sauvegarde locale.
